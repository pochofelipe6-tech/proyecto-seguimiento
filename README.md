# Kilometraje

Aplicación web estática para registrar recorridos y calcular el kilometraje acumulado por persona.

## Funciones

- Cálculo automático a partir del odómetro inicial y final.
- Totales generales, mensuales, por recorridos y por personas.
- Historial con búsqueda y eliminación de registros.
- Persistencia local en el navegador.
- Exportación del historial a CSV.

Para usarla localmente, sirve la carpeta `dist` con cualquier servidor HTTP estático.
