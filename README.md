# Ruta Segura

Aplicación web preventiva para monitorear la velocidad con GPS y registrar excesos por conductor, placa, sector y tipo de zona.

## Funciones

- Monitoreo de velocidad mediante GPS del dispositivo.
- Límites SST para zona urbana, vía nacional, curvas y zona escolar/residencial.
- Alarma sonora, vibración y notificación ante un exceso.
- Registro de fecha, hora, conductor, placa, sector, coordenadas, límite y velocidad.
- Indicadores, filtros, búsqueda y exportación a CSV.
- Persistencia local en el navegador.

Para usarla localmente, sirve la carpeta `dist` con cualquier servidor HTTP estático.
